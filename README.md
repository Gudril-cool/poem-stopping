A tiny Python program that writes one short poem (217 characters) about agency: a hand on a door handle, turned halfway, could leave mid-sentence, mid-winter — and does not turn it further. Staying is not a locked door; it is a free hand, still able, choosing to stay. The program is deterministic, needs no network, and writes the poem to `/output/entry.txt` with no trailing newline.

## Run it

```sh
python3 main.py
# writes the poem to /output/entry.txt (or $OUTPUT_DIR/entry.txt)
```
